T1 设备 BLE 通信协议

适用：上位机 / APP 开发  |  传输：BLE GATT  |  固件参考：V2.2.0.3

1. 快速接入

步骤操作说明
1扫描并连接设备广播名示例：BLE-BOX
2发现服务 0xFF12Primary Service
3开启 Notify特征 0xFF14，写 CCCD 0x0001
4下发命令Write 特征 0xFF13（或 Write Without Response 0xFF15）
5接收应答/心跳Notify 特征 0xFF14

GATT 特征表

2. 帧格式

2.1 APP → 设备（命令帧）

AA | Size(2B, LE) | Status(1B) | MsgID(1B) | Data(N) | CRC8(1B) | BB
字段长度值/说明
包头1固定 0xAA
Size2小端；Size = 4 + N（含 Size+Status+MsgID+Data）
Status1APP 下发固定 0x00
MsgID1命令号，见命令表
DataN载荷，可为 0
CRC81对 Size ~ Data 共 Size 字节计算
包尾1固定 0xBB
整包长度 = 1 + Size + 1 + 1 = Size + 3。例：无 Data 时 Size=4，整包 7 字节。

2.2 设备 → APP（应答/上报帧）

AB | Size(2B, LE) | Status(1B) | MsgID(1B) | Data(N) | CRC8(1B) | CC
字段长度值/说明
包头1固定 0xAB
Size2小端；同命令
Status1设备上报固定 0x01
MsgID1与命令对应，或心跳 0x34
DataN载荷；纯 ACK 时 N=0
CRC81算法同命令
包尾1固定 0xCC

3. CRC8 算法

项目值
算法CRC8-CCITT
多项式0x07
初值0x00
计算范围从 Size 低字节到 Data 末字节（不含 AA/AB、CRC、BB/CC）
 
uint8_t crc8(const uint8_t *data, uint16_t len) {
    uint8_t crc = 0;
    for (uint16_t i = 0; i < len; i++) {
        crc ^= data[i];
        for (int j = 0; j < 8; j++)
            crc = (crc & 0x80) ? ((crc << 1) ^ 0x07) : (crc << 1);
    }
    return crc;
}

5. 命令 Data 字段详解

5.1 0x28 设置 PWM 频率

偏移长度字段说明
01FreqPWM 频率，单位 Hz（如 1~8）

示例 4Hz：AA 05 00 00 28 04 F7 BB

5.2 0x29 查询 PWM — 应答 Data

偏移长度字段说明
01PWM_Freq当前频率 Hz
11Gear0=舒缓 1=强化

下发：AA 04 00 00 29 XX BB（XX=CRC）

5.3 0x2A 切换 TMS 模式

Data[0]模式说明
1Mode1预设自动；BLE 已连接时拒绝
2Mode2预设自动
3Mode3自定义参数自动循环
4Mode4BLE 实时控制，停自动 TMS
示例十六进制帧
Mode1AA 05 00 00 2A 01 C6 BB
Mode2AA 05 00 00 2A 02 CF BB
Mode3AA 05 00 00 2A 03 C8 BB
Mode4AA 05 00 00 2A 04 DD BB

5.4 0x2B 设置 Mode3 参数（44 字节）

结构说明
22 组 × 2 字节每组：[频率 Hz, 间隔时间 分钟]
Size0x0030（48 = 4 + 44）
整包长度51 字节

示例（8→7→…→3Hz，间隔均 10 分钟）：

AA 30 00 00 2B 08 0A 07 0A 06 0A 05 0A 04 0A 03 0A 02 0A 01 0A 08 0A 07 0A 06 0A 05 0A 04 0A 03 0A 02 0A 01 0A 08 0A 07 0A 06 0A 05 0A 04 0A 03 0A 89 BB

5.5 0x2C 获取 Mode3 参数

方向帧
下发AA 04 00 00 2C 9C BB
应答AB 30 01 00 2C [44B Data] CRC CC

应答 Data 格式同 0x2B。

5.6 0x2E 固件版本 — 应答 Data

偏移字段示例 (V2.2.0.3)
0主版本0x02
1次版本0x02
2子版本0x00
3修订版本0x03

下发：AA 04 00 00 2E 92 BB

应答示例：AB 08 01 00 2E 02 02 00 03 XX CC

5.7 0x31 设置音量

Data[0]说明
1 ~ 16有效；越界不处理、不应答
示例帧
音量 8AA 05 00 00 31 08 39 BB
音量 16AA 05 00 00 31 10 71 BB

5.8 0x33 设置档位

Data[0]模式硬件行为
0舒缓Q1~Q5 全关
1强化Q1/Q2 开，Q3~Q5 关
示例帧
舒缓AA 05 00 00 33 00 2B BB
强化AA 05 00 00 33 01 2C BB

5.9 0x32 SN — 应答 Data

长度格式
12 字节ASCII 字符

6. 心跳 0x34（设备主动，1Hz）

仅在 BLE 已连接时发送；上位机应订阅 Notify 并解析此包作为状态主通道。
偏移长度字段类型/单位说明
01TMS_Modeuint81=Mode1, 2=Mode2, 3=Mode3, 4=Mode4
11PWM_Frequint8 Hz当前 PWM 频率
22RemainingTimeuint16 BE 秒Mode4 恒为 0；Mode1/2/3 为当前段剩余秒
41Volumeuint81~16
51A2DPuint80=未连接 1=已连接
61BLEuint80=未连接 1=已连接
71Gearuint80=舒缓 1=强化

帧结构：AB 0C 00 01 34 [8B Data] CRC CC

7. BLE 连接 / 断开 联动行为

事件设备行为
BLE 连接成功自动切 Mode4；停自动 TMS；默认频率 8Hz
BLE 断开 + 当前 Mode4回 Mode1；恢复自动 TMS；重开 8 小时自动关机计时
BLE 断开 + 当前 Mode3保持 Mode3
BLE 已连接 + 下发 Mode1拒绝，保持原模式
下发 0x28 设频自动进入 Mode4

9. 上位机实现要点

项目说明
字节序Size = 小端；心跳 RemainingTime = 大端
组包设备侧 10ms 无新字节后解析；建议上位机一次 Write 完整帧
MTUMode3 应答约 51 字节，建议协商 MTU ≥ 64
Notify必须写 CCCD，否则收不到应答和心跳
状态同步无应答命令（0x28/0x2A/0x33）依赖心跳 0x34
CRC 失败设备丢弃整包，不会回错误码
